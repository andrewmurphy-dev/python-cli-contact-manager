# Python CLI Contact Manager

A command-line contact manager built while learning Python fundamentals and backend programming concepts.

This project is part of my structured Python learning roadmap and focuses on building real programs rather than isolated exercises.

## Purpose

The goal of this project is to practice core backend programming concepts including:

- data storage using dictionaries
- nested data structures
- command-line interface (CLI) program design
- CRUD operations (Create, Read, Update, Delete)
- modular code organization

## Features (in progress)

- Add contact
- Search contact
- Update contact
- Delete contact
- Display contacts
